# 大模型应用开发基础01：基础概念

## 发展历程与区别：

- 什么是**人工智能**？
  - 机器可以像人一样做事情。
    - 做法：用程序写好规则，让机器按规则做事。

- 什么是**机器学习**？
  - 机器自己通过【题目+标准答案】找出规律或答案
    - 做法：**人工对题目和规则打标签、设计特征**。机器通过算法，提取特征类似的问题和答案。【这里会设计到一些向量计算】

- **深度学习**？
  - 机器自己打标签和设计特征。
    - 做法：通过神经网络，一层一层筛选特征。【比如一张图，第一层提取色块，第二层通过色块相似值进行边缘组合成耳朵或眼睛；第三层把图形拼装成猫脸】
      - 2012年的 AlexNet 图像识别大赛极大提升了识别成功率。随后就出现了人脸识别、语言识别

- **ChatGPT 生成式AI**？
  - 之前的都是识别判断。而生成式AI就是自己造东西。ChatGPT就是生成式AI
    - 做法：**根据前文，预测下一个字**。
      - Transformer架构：引入**自注意力机制（self-Attention）**，让模型处理词的同时，能看到看到整句话的其他词，自动算出“谁跟谁关系更近”。然后它可以并行训练，极大提高了效率
    - ChatGPT是怎么做的？
      - 就是把整个互联网的公开文本都喂给大模型。形成了LLM（大语言模型）。所以最初的ChatGPT就是只会做文本补全。

- **多模态与AIGC**？
  - 最初的大模型都是只会文本。对图都不太行
  - **多模态就是文字、图像、视频等多种模态**（信息等形式）
    - Transformer处理的不是文字而是向量。那么图像、视频也可以处理成向量喂给大模型。所以就有了可以识别图片、视频的模型
  - **AIGC是指人工智能生成内容**
    - 相当于从单独文本生成，变成了什么内容都可以生成了。

- **Agent**？
  - 上面说的都是读取生生成，但是不会执行。
    - 比如你让最初的ChatGPT帮忙订个机票，它会告诉你订票步骤，但是它无法真实操作电脑打开携程、输入身份证、完成支付这一系列动作
  - Agent其实就相当于让大模型具有工具调用能力。 **Agent = 大模型 + 工具 + 记忆 + 规划 + 反馈循环。**然后它可以通过拿到结果再循环进入下一步，直到任务完成。
    - OpenClaw则是一个能让大模型操作你电脑的Agent

## 大模型应用术语：

- **Token**：
  - 可以理解为字节或文字，但是它实际上是分词。通过使用频率来编写的，比如常见的词汇基本是1个token，不常见的词汇可能文字较少，但是占用跟多token。最终形成一个大模型看的懂的高频分词表
    - 大模型既不按单词读、也不按字读，而是用一张【高频片段表】把你的输入压成最近的Token序列。它不关心语法，只关心频率。

- **上下问窗口**：
  - 是指一次请求中，大模型能处理的最大Token数量。通常是输入+输出的总和。
    - 常听说的多少万Token，指的就是上下文窗口可以容纳的Token数
    - **大模型本身是没有记忆的，接口调用也是无状态的**。我们使用应用看到的是应用存在自己数据库里的，跟模型无关。你每次发消息，其实是应用把【历史对话+这条新消息】打包成一整段。
> 大模型本身是没有记忆的，接口调用也是无状态的。

    - 所以对话越长，迟早要超出上下文窗口上限。一旦超限，大模型就会之间报错失败。善后工作就得由应用自己做，3种处理方式
      - 截断：指保留最近N轮对话，丢弃早起记录。代价是会突然失忆
      - 压缩：将早期对话交给模型总结成一段摘要，摘要重新作为上下文的一部分发给大模型。但是细节一定有损失。
      - 提示新开会话：
    - 所以大模型本身是没有记忆的，接口调用也是无状态的。

- **Prompt**
  - 就是喂给大模型的文本
    - 通常分为System Prompt（系统提示词） 和User Prompt（用户提示词）
      - System Prompt：通常由开发者在后台加入，一般不出现在聊天界面。比如设置权限
      - 一般System Prompt 是写的不可突破的底线，User写的是具体需求。底线不可破，需求可以灵活响应。

- **大模型不等于大模型应用**：
  - **大模型应用 = 模型调用 + 会话于状态管理 + 上下文组装 + 知识检索（RAG） + 工具调用 + 输出校验与格式约束 + 重试、降级与限流 + 成本、延迟与效果监控 + 安全与合规 + 任务编排 + ...**

- **Agent智能体**：
  - Agent智能体其实也是大模型应用的一种。
  - 一般的大模型应用，可以分为3档：
    - 1、单次调用：发一段Prompt，模型回一段结果
    - 2、WorkFlow：将任务拆成几步。模型负责拆分任务，各个步骤的编排，但是不参与决策。**每一步走到哪、下一步干什么，是人决定的。**
    - 3、Agent智能体：只提供目标和工具，程序会进入一个循环：**思考，调用工具，看结果，再分析，再调用工具，再得出结果，直到它认为任务完成**。
      - 比如cursor等编程Agent：输入目标，它会自己去查找文件、读代码、动手改、跑测试，如果测试没通过，它会再改，再来一轮。
      - 但是也存在带着工具反复调用，越跑越偏。所以agent应用开发需要给他定边界、控成本等等
