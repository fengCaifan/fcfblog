# 动态规划

动态规划：

将复杂的原问题拆解成若干个简单的子问题

每个子问题仅仅解决1次，并保存它的解。

- 可以用动态规划来解决的问题，通常具备2个特点
  - 最优子结构（最优化原理）：通过求解子问题的最优解，可以获得原问题的最优解
  - 无后效性：
    - 某个阶段的一旦确定，则此后过程的演变不再受此前各状态和决策的影响（未来与过去无关）
    - 在推导后面阶段状态时，只关心前面阶段的具体状态值。
    - 有后效性的题是无法用动态规划求解的。

经典例题：

[53. 最大子数组和](https://leetcode.cn/problems/maximum-subarray/submissions/538453190/)

最长连续子数组和

使用动态规划，定义的dp就是表示：以i节点结束的最大连续子数组和。则最终的结果，肯定就是dp数组里的最大值

```swift
class Solution {
    func maxSubArray(_ nums: [Int]) -> Int {
        guard let first = nums.first else { return 0 }
        var dp: [Int] = nums // 表示以i结尾的连续子序列和
        var maxSub = first
        var i = 1 
        while i < nums.count {
            if dp[i - 1] < 0 {
                dp[i] = nums[i]
            } else {
                dp[i] = dp[i - 1] + nums[i]
            }

            maxSub = max(maxSub, dp[i])
            i += 1
        } 
        return maxSub
    }
}
```

解决动态规划的核心：**找出子问题及其子问题与原问题的关系**。

动态规划算法中关于最优子结构和重复子问题的理解的关键点：

1、证明问题的方案中包含一种选择，选择之后留下一个或多个子问题

2、设计子问题的递归描述方式

3、证明对原问题的最优解包括了对所有子问题的最优解

4、证明子问题是重叠的（这一步不是动态规划正确性必需的，但是如果子问题无重叠，则效率与一般递归是相同的）

## 动态规划

- 动态规划解题思路有两个核心部分：
  - **确定**动态规划**状态（也叫DP状态）**
  - **确定**动态规划**转移方程（也叫DP转移方程）**

### 动态规划状态

- DP状态的确定主要有两大原则：最优子结构和无后效性。

#### 最优子结构

- 将原有问题划分为一个个子问题，即为子结构

- 而对于每一个子结构的最优值均由“更小规模子结构的最优值”推导而来。此时这个子问题的最优值即为“DP状态”
