# 二叉树及其衍生结构

在数据结构中，数组和链表是线性结构，**数组适合遍历查找但是不适合插入删除，链表适合插入删除但是不适合遍历查找**。二叉树则是非线性结构，是它自身的树形结构。当二叉树只有单一左子树或者右子树的情况下，那它其实就是劣化成了链表。

整体来说，二叉树的遍历查找效率（O(log n)）比链表O(n)高，但是比数组O(1)效率低；插入删除比数组效率高，但是比链表效率低。可以说正好是一个比较中庸的结构，所以它的使用非常广泛。

其次二叉树有非常多种结构，不同的结构适合做不同的事情，比如：

- **满二叉树**：二叉树的每一层节点数都是满的。节点总数N = 2 ^ H - 1，H是二叉树的高度。ps：因为每一层的数量都是上一层数量的2倍。
  -  **完全二叉树**：除最后一层外，每一层都是满节点，且最后一层子节点都连续集中在最左边。所以完全二叉树是满二叉树衍生出来的。**它的第一个非叶子节点的下标是size/2 - 1；第i个节点的父节点下标是(i-1)/2。**
  [**满二叉树与完全二叉树**](https://zhuanlan.zhihu.com/p/152285749)

- **二叉搜索树**：二叉搜索树是有序的，每一个左子树的节点的值都要小于根节点，每一个右子树结点上的值都要大于根节点。（注意是每一个树，包括每一个子树），所以这是一个**排序好**的结构。[二叉搜索树](https://zhuanlan.zhihu.com/p/445947036)
  - **平衡二叉搜索树（AVL树）**：首先它是二叉搜索树，其次它是平衡的，即每个节点的左子树高度和右子树高度差最多为1，因为越平衡搜索效率越高，所以就衍生出这么个子类。[平衡二叉搜索树](https://zhuanlan.zhihu.com/p/438604092)
    - 注意：平衡和满的区别：平衡是指左右子树的高度差最多是1，并未要求是左子树高还是右子树高；满的话，是最后一层左侧必须是满的，也就相当于必须是左子树高（或者相等）。
  - 红黑树：把树的节点定义为红黑两种颜色，并通过规则确保从根节点到叶子节点的最长路径的长度不超过最短路径的两倍。
    - 很多数据结构底层都是用红黑树实现的。比如STL中的set、map等。

## 关键数据

### 二叉树

- 非空二叉树的第i层，最多有2^(i-1)个节点（i>=1）

- 在高度为h的二茶树，最多有2^h - 1个节点

- 对于任一一颗非空二叉树，如果叶子节点个数为n0，度为2的节点个数为n2，则 n0 = n2 + 1

##### 真二叉树

- 所有节点的度要么为0，要么为2

##### 满二叉树

- 所有节点的度要么为0，要么为2。且所有的叶子节点都在最后一层。

- 假设满二叉树的高度是h(h >= 1)，那么第i层的节点数量为：2^(i-1)；叶子节点数量2^(h-1)；总节点数量 n = 2^h - 1

##### 完全二叉树（二叉堆）

- 叶子节点只会出现在最后2层，且最后1层的叶子节点都靠左对齐。

- 度为1的节点只有左子树；度为1的节点要么是1个，要么是0个

- 假设完全二叉树的高度为h（h>=1）,那么
  - 至少有2^(h-1)个节点
  - 最多有2^h - 1 个节点
  - 总节点数n，则 2^(h-1) <= n < 2^h, ----> h - 1 <= log2n < h,   所以 h = floor(  log2n  ) + 1。floor向下取整

- 一个有n个节点的完全二叉树（n > 0 ），从上到下，从左到右对节点从1开始进行编号，对任意第i个节点：
  - 如果i=0，它是根节点
  - 如果i > 0，它的**父节点编号为floor(i- 1)/2**
  - 如果2i + 1 <= n - 1，它的左子节点编号为2i + 1 , 右子节点编号为2i + 2
  - **第一个非叶子节点下标： size / 2 - 1**

- **面试题：如果一棵完全二叉树有768个节点，求叶子节点的个数:**
  - 假设叶子节点个数是n0，度为1的节点个数为n1，度为2的节点个数为n2;
  - 则总节点个数n = n0 + n1 + n2, 且 n0 = n2 + 1
  - 所以 n = 2n0 + n1 - 1
  - 又因为完全二叉树n1要么为0，要么为1；
  - 所以：
  - n1 = 1时，n = 2n0, n必然是偶数；叶子节点个数n0 = n/2, 非叶子节点个数 n1 + n2 = n / 2
  - n1为0时，n = 2n0 - 1，n必然是奇数；叶子节点个数n0 = (n + 1) / 2，非叶子节点个数n1 + n2 = (n - 1) / 2
  - 所以，在代码层面：n0 = floor( (n + 1)/2 )
